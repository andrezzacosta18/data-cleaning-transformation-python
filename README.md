# 📖 Overview

This project was developed as part of the **Data Analyst Programme** at **CESAE Digital**.

The objective is to assess the quality of a dataset, identify inconsistencies, perform data cleaning and transformation, and develop an interactive Python application for Excel data management.

The project follows software engineering best practices, including modular programming, documentation, and version control.

---

# 🎯 Objectives

- Explore and understand the dataset.
- Assess data quality.
- Detect missing values and duplicate records.
- Analyse categorical and numerical variables.
- Identify potential outliers.
- Clean and standardise the dataset.
- Export the processed dataset.
- Manage Excel files through an interactive Python application.

# 💻 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/data-cleaning-transformation-python.git
```

Navigate to the project directory:

```bash
cd data-cleaning-transformation-python
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the virtual environment.

### Windows

```bash
.venv\Scripts\activate
```

### macOS / Linux

```bash
source .venv/bin/activate
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

---

# ▶️ Running the Project

### Module 1

Open the notebook:

```text
notebooks/01_data_quality_analysis.ipynb
```

### Modules 2 and 3

Run:

```bash
python src/main.py
```
